## 🌟 About RTLH

Rwanda Tech Learning Hub is being developed as a technology-powered learning platform designed to make education more:

**Accessible • Practical • Interactive • Connected • Creative • Future-ready**

RTLH brings multiple learning experiences together:

* 🎓 Online courses
* 🧑‍🏫 E-Teacher
* 🏫 E-Class
* 📖 E-Library
* 🤖 Theo Learn Wise AI
* 📊 Learning dashboards
* 🏆 Certificates
* 🌍 Jobs & opportunities
* 🎓 Scholarships
* 💼 Internships
* 🤝 Mentorship
* 👥 Community
* 💡 Partnerships
* 💚 Sponsorship

The platform is designed to serve learners, teachers, schools, organizations, creators, and lifelong learners.

# 🎓 Learning Center

The RTLH Learning Center is the main gateway into the platform.

Learners can discover and access:

### 📚 Courses

Courses can be organized by:

* Educational level
* Domain
* Category
* Subject
* Skill
* Learning pathway
* Course type

The architecture supports both **free and paid learning experiences**.

### 🎯 Learning modes

* Self-paced
* Teacher-led
* Live classes
* Structured learning pathways
* Interactive assessments


 🧑‍🏫 E-Teacher

RTLH E-Teacher is designed to give educators a digital environment for creating and managing learning.

Teachers can work with:

* Classes
* Lessons
* Assignments
* Quizzes
* Tests
* Projects
* Exams
* Homework
* Announcements
