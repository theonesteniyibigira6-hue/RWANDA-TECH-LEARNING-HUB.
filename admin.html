This dashboard cannot replace Firestore Security Rules. Protect the database using Firebase Authentication plus role-based rules.
Security checklist
  • Firebase Authentication enabled.
  • Exact admin account restricted.
  • Role-based Firestore rules.
  • No passwords in source code.
  • Private learner data protected.
  • Audit logs reviewed.
